# GK7205V300 + Sony IMX307 @ 60 FPS Configuration & Testing Pipeline

Проект настройки и тестирования связки процессора **Goke GK7205V300** и сенсора **Sony IMX307** в разрешении 1080p при частоте **60 кадров/с** под управлением OpenIPC (стример Majestic).

## Структура репозитория
- `.github/workflows/test.yml` — CI/CD пайплайн сборки и запуска тестового контейнера в GitHub Actions.
- `Dockerfile` — изолированное тестовое окружение на базе Alpine Linux.
- `test/run_tests.sh` — тесты валидации YAML/INI синтаксиса и параметров 60 FPS.
- `configs/majestic.yaml` — профиль стримера Majestic (1080p60, lowDelay, CBR).
- `configs/imx307.ini` — параметры тактирования сенсора IMX307 (37.125 МГц, 60 к/с).

## Ключевые параметры для 60 FPS
1. **Частота кадров:** `video0.fps: 60`, `size: 1920x1080`.
2. **Задержка:** `isp.lowDelay: true` (снижение задержки на ~17 мс).
3. **Экспозиция:** максимальная выдержка не более 1/60s (`exposure.max: 16666`), предотвращающая просадку FPS в темноте.
